# Design Document

## UI/UX Principles
- Minimalist layout with warm neutral tones
- Serif headers and clean sans-serif body text
- Responsive design for desktop and mobile

## Components
- **Header:** Branding and model selector
- **ChatPane:** Interactive chat interface
- **ArtifactViewer:** Displays generated insights
- **Footer:** Attribution and version info

## Interaction Flow
1. User enters a question.
2. ChatPane displays streaming AI response.
3. ArtifactViewer shows structured output (summary, report, or insight).

## Accessibility
- High contrast text
- Keyboard navigation support
- ARIA labels for screen readers
